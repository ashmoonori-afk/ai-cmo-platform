# Quarantined AI Marketing Methods

This directory contains a human-reviewable, reference-only adaptation of a small
approved subset of `ericosiu/ai-marketing-skills`. The upstream repository is
untrusted input. Nothing here is an installed skill, loader entrypoint, prompt,
workflow, or executable component.

## Trust boundary

- Default loading: disabled
- Activation: none
- Execution approval: false
- Network access: false
- Runtime integration: none
- Intended use: manual consultation of the sanitized methodology only

The material must not be renamed to an active skill basename or moved into an
active loader surface without a separate security review and explicit approval.
