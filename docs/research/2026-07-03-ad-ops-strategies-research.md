# PART A. 실험 설계 전략

## A1. Meta 공식 A/B 도구 vs 수동 분할

- 공식 A/B(Experiments): 오디언스 중복 없이 무작위 분할, 결과당 비용 기준 승자 판정 (공식: facebook.com/business/help/1738164643098669)
- 권장 기간 **최소 7일~최대 30일** (전환 소요 길면 10일+) — Benly 2026, Get-Ryze 2026 교차검증
- 승자 선언 기준 **신뢰도 65% 이상** (홀드아웃 90%) — Coinis, Kirro
- 세팅 화면 "예상 검정력" 80% 미만 = 예산/기간 부족 — Seer Interactive. 최소 예산 절대금액: 모름 (계정별 동적 산출)
- 소액 계정: 공식 도구는 큰 구조 결정에 연 몇 회만, 소재 비교는 A4 수동 루틴

## A2. 테스트→스케일 2캠페인 구조

- ABO 테스트(예산 고정 공정 비교) → 승자를 **Post ID 그대로** CBO/ASC 스케일 캠페인에 복제 — Superscale 2026, RebootIQ, Skaleit 공통
- 신규 컨셉은 예산 10~15%로 별도 테스트 후 승자만 투입 (AskNeedle)
- 근거 수치 (Meta 발표 2차 인용): ASC 전환당 비용 17%↓, 학습 통과 광고 CPA 19%↓, 세트 수 축소 광고주 CPA 68%↓ (Tiger Pistol — Performance 5)
- 소액: "테스트 캠페인(소재 3~5) + 스케일 캠페인(검증 소재만)" 2캠페인으로 축소

## A3. 예산 분할 70/20/10 → 소액은 80/20

- 70 검증 / 20 유망 확장 / 10 실험 — Coca-Cola Content 2020(Mildenhall)·Google 채택 (Connective, Barrett Media 2024). 광고계정 버전: GeoGrowth Media
- ASC 변형: 검증 85~90% + 테스트 10~15% (AskNeedle)
- 월 100만 원 미만: **80/20 2분할** + 실험 몫은 분기 1회 [추정 — 소액 변형 공식 출처 없음]

## A4. 크리에이티브 테스트 설계 (핵심)

- **1변수 통제** (Meta 공식 베스트 프랙티스)
- **컨셉 → 변형 2단계**: 신규 컨셉끼리 경쟁 → 승자 컨셉의 훅/헤드라인만 변형 최적화 (Motion 2025)
- **킬 룰 (지출액 기준 — 기간 아님)**:
  - 목표 CPA 2배 지출 + 전환 0 → 즉시 종료 (NPPR 2026)
  - 노출 1,000회 후 CTR 1% 미만 → 소재 문제 판정 (AdStellar)
  - 목표 CPA 3배 지출 + 전환 0 → 조합 폐기
  - **72시간 내 즉시종료 기준 외 킬 금지**
- 3:2:2 메소드 (참고 — 소재3×본문2×헤드라인2 DCT): 실무자 계열 출처, 신뢰 하위
- 한국 실무: 소재당 일 1천~5천 원 소액 A/B 후 증액 (polarad 2025, ampm)

## A5. 증분(Incrementality) 테스트

- Meta Conversion Lift: 홀드아웃 10~20% RCT — **최소 $30,000 지출 요구** → 소액 불가 (Triple Whale)
- Geo 홀드아웃 간이형: 홀드아웃 지역 2~4 + 컨트롤 4~8, 4~8주 (Funnel.io, Meta GeoLift)
- **초간이 On/Off**: 의심 캠페인(리타겟/브랜드검색) 1개만 1~2주 OFF → 총매출 낙폭 대조. 낙폭 < 보고 매출이면 증분 낮음 (Funnel.io, Cometly 2026) — 소액 계정의 유일한 현실 옵션, 비용 0원

## A6. 랜딩페이지 실험

- 정석: Google Ads Custom Experiments — 캠페인 복제, URL만 변경, **50/50 분할**, 2~4주 (Google 공식 support.google.com/google-ads/answer/6261395)
- 함정: "광고 2개에 URL 2개"는 알고리즘 배분 편향으로 가짜 A/B (Blobr)
- 실패 1위 원인 = 트래킹/UTM 깨짐 — 사전 검증 필수
- 소액: 미세 변형 말고 **큰 차이(오퍼·가격 표시·구조)만** 테스트 [추정 — 표본 원리]

## A7. 네이버 검색광고 실험

- 소재 **성과기반 노출** 공식 설명 (2017-07~): 클릭 확률 모델 + 시뮬레이션으로 노출 비중 자동 배분, 소재 2개+일 때 작동 (아이보스 — 네이버 공지 전재)
- **성과기반은 클릭 기반이라 전환 판정에 부적합** → 전환 중심이면 **동일비중 + 전환 데이터 수동 판정** (브런치 파워링크 가이드)
- 키워드 테스트: 확장검색 상한 10~20%로 "발굴기"로만 + 주 1회 검색어 리포트 → 제외키워드 정리 루프 (적정마케팅연구소, 고도몰 2025)

# PART B. 지표 해석 전략

## B1. 플랫폼 ROAS vs 블렌디드 MER

- **MER = 총매출 ÷ 총광고비** (전 채널 합산). 플랫폼 ROAS = 상대 비교용 / MER = 절대 판단용
- 인플레이션 근거: Meta 평균 **~28% ROAS 과대보고**, 채널 합산 30~40%, 중복 심하면 70%+ (AdsX); 같은 주문을 Meta·Google이 각각 청구하는 이중 계상 (Polar Analytics)
- 프레임 출처: Common Thread Collective(Taylor Holiday), iOS14 이후 표준화 (Superscale 2026, Northbeam)
- 소액 적용: 주간 총매출÷총광고비 1줄 + 플랫폼 ROAS와의 갭 기록 → 자기 계정 인플레이션율 파악

## B2. 판정 최소 표본 룰

- CRO 기준: 변형당 전환 250~350건 미만 결과는 뒤집힘 (CXL) — 소액 불가능
- 광고 실무 최소 게이트: **목표 CPA 1~2배 지출 + 노출 1,000회 + 72시간** (AdStellar, NPPR 2026)
- 이 표본으로는 "대패자 제거"만 가능, "미세 승자 확정" 불가 — SOP에 명시
- Meta 공식: A/B 신뢰도 65% 미만 승자 미선언, 학습 완료 = 세트당 주 ~50전환

## B3. 어트리뷰션 윈도

- Meta 기본 7일 클릭+1일 뷰. 윈도가 보고 수치와 **알고리즘 최적화 대상 둘 다** 바꿈 (짧은 윈도 = 즉시구매형 편향 배달 — AdsManagement 2026)
- 세팅 변경 없이 "어트리뷰션 비교" 컬럼으로 1DC/7DC 병렬 조회 가능
- 윈도 간 % 편차 일반화 수치: 모름
- 적용: 윈도 고정(리드젠 1DC / 이커머스 7DC+1DV), 기간 비교 시 변경 금지, 월 1회 1DC 비중 확인

## B4. 지표 우선순위 트리 (결정은 CPA, 진단은 CTR/CVR)

```
CPA/MER 나쁨?
├─ CTR 벤치마크 미달        → 크리에이티브/타겟 문제 (소재 교체)
├─ CTR 정상 + CVR 낮음      → 랜딩/오퍼 문제 (페이지 수정)
├─ CTR·CVR 정상 + CPM 급등  → 경매/오디언스 원가 (타겟·시즌 확인)
└─ 둘 다 약함               → 증액 전에 크리에이티브부터
```
근거: Digital Applied 2026, Pathlabs (지표 계층 구분)

## B5. 시간 요인 보정

- 학습기: 첫 48시간 CPA 3배 스파이크 = 정상 변동, 24~48h 데이터로 중단 금지 (AdStellar)
- 요일: 전환율 요일 변동 최대 30% (LeadEnforce) → **온전한 주 단위(월~일)로만 비교**, 7일 롤링 고정
- 계절성: 전주 동요일·전년 동기 대조, 프로모션 기간 라벨링 [실무 통칙, 추정 포함]

## B6. 흔한 오독 6종

| 오독 | 실제 | 근거 |
|------|------|------|
| 초기 과성과 = 승자 | 소표본 착시, 주간 사이클 후 역전 빈번 | CXL, AdStellar |
| CTR 높은 소재 = 승자 | 호기심 클릭 — CVR 낮은 조합 흔함 | Smart Insights, KlientBoost |
| 리타겟 ROAS 10배 = 효자 | 증분 대비 2~5배 부풀림, 진짜 증분 40% 사례 | Nine.am, Improvado, Stackmatix |
| 브랜드검색 ROAS = 광고 성과 | 오가닉이 공짜로 잡을 수요를 광고가 청구 | RightSideUp |
| 채널 ROAS 합산 = 총성과 | 같은 주문 중복 청구 (합산 > 실매출) | Polar Analytics |
| 학습기 CPA 급등 = 실패 | 탐색 과정 정상 변동 | AdStellar |

# PART C. 컨텐츠(크리에이티브) 전략

전제 근거: 광고발 매출 상승분의 49%가 크리에이티브 요인 (Nielsen Catalina ~500 CPG 캠페인, nielsen.com 2017 — 표준 인용 연구); Andromeda(2024-12 공식)로 크리에이티브가 델리버리 핵심 입력화 (engineering.fb.com).

## C1. UGC/네이티브 스타일

- Meta 공식 Performance 5의 기둥 (facebook.com/business/news/meta-performance-5-techniques)
- VidMob 실측 (TikTok 광고 1,678개·노출 73억, 2023): 일반인/공감형 오프닝 = 브랜드 적합 인식 +20%, 정면 토킹헤드 = 2초 시청 +14%, 얼굴/미소 +13% (vidmob.com)
- 4만 개 DTC 광고 분석 (2025): "스텔스 UGC"로 진화 + 폴리시드와 하이브리드 운용 (blog.theperformers.io/p/9-figure-dtc-report)
- 주의: "UGC 3~5배" 류 배수는 1차 데이터 미공개 [추정 취급 금지 — 수록 배제]
- 적용: 폰 세로 촬영 + 자막 + 첫 컷 얼굴. 사장님/직원 후기 포맷부터

## C2. 크리에이티브 다양화 (Andromeda 이후)

- **Meta 공식 피로도 연구 (실험 ~26,000건, 2023): 동일 소재 4회 노출 시 전환 가능성 약 −45%** (medium.com/@AnalyticsAtMeta)
- AppsFlyer 2025 (영상 변형 110만·광고비 $24억): 상위 2% 소재가 광고비 43~53% 흡수 — 다양화 테스트 필수
- Motion 2026 (광고 55만·지출 $13억): 광고의 5~8%만 위너
- 적용: "진짜 다른" 컨셉 유지 — 저예산은 3~5개 (UGC형/제품/문제해결/비포애프터/후기형). 색만 바꾼 변형은 다양화 아님 [경험칙]

## C3. 포맷 믹스 (실측)

- Lebesgue 2025-03 (이커머스 집계): 캐러셀 CVR 1.39% > 이미지 1.26%, CAC 캐러셀 $15.47 vs 이미지 $27.97; CTR은 영상 우위, CPM은 이미지 최저($1.56)
- 4만 개 DTC: 상위 브랜드 영상 비중 29~76% 제각각 — 정답 포맷 없음, 전부 믹스
- 적용: 이미지로 앵글 검증(싸게) → 검증 앵글만 영상화 → 제품·후기 많으면 캐러셀

## C4. 앵글(소구점) 프레임워크

- 표준 5앵글: 문제-해결 / 사회적 증거 / 창업자 스토리 / 비포-애프터 / 작동 원리 + 비교형(us-vs-them)
- 근거: 4만 개 DTC 상위 브랜드 공통 패턴 (비교형·변화형·호기심·적 지정); AppsFlyer — **"실패→성공" 스토리가 순수 성공담 대비 IPM +78%**
- 운용 표준: 3~5앵글 × 앵글당 2~3변형 (ATTN, Pilothouse 2025-26)
- 적용: 제작 전 앵글 맵 작성. 비교형은 경쟁사 실명 대신 "구형 방식"을 적으로 (표시광고법 리스크 회피)

## C5. 어글리 애드/로우파이

- Pattern Brands: "광고 4개 중 3개는 못생긴 쪽이 이김" (Modern Retail); 메커니즘 = 고제작비 → "광고다" 신호 → 스킵 반사 (Search Engine Land 2026-04)
- 대규모 실측 데이터셋 미확보 [부분 검증 — VidMob 간접 근거]
- 적용: 예산 20%만 어글리 실험 (카톡 스크린샷 스타일, 손글씨 가격표). 의료 등 신뢰 업종은 폴리시드 유지

## C6. 카피 길이

- Meta 공식 권장 프라이머리 125자 (한글 체감 60~80자), "더 보기" 클릭 ~1.05% [3자] = 99%는 첫 줄만 읽음
- AdEspresso $1,000 실험 (2018 — 오래됨 명시): 3문단 중장문이 CPA 최저, 한 문장이 최악
- 적용: 첫 125자 = 광고 전체로 취급 (훅+오퍼+CTA), 이하는 1% 고관여자용 상세. 단문+중장문 동시 테스트

## C7. 리프레시 전략

- Meta 공식: 4회 노출 −45% (C2) + 광고관리자 "크리에이티브 피로" 상태 표시 공식 제공
- Andromeda 이후 수명 6~8주 → 2~3주 압축, 빈도 2~3 도달 시 7~14일 리프레시 [업계 종합, 1차 미확인 — 추정]
- TikTok 공식: 성과 하락 일관 시 기존 그룹에 새 소재 추가 (신규 그룹 생성보다)
- 적용: 주간 지표 = 7일 빈도 3 초과 + CTR 피크 대비 −25%. 교체는 전면이 아니라 **훅만 교체**가 최저비용. 소상공인 최소 루틴: 2주 1회 신규 2개

# PART D. 후킹 전략

## D1. 훅 유형 분류 (데이터 있는 것)

- 결과/변화 먼저(payoff-first): 실패→성공 IPM +78% (AppsFlyer 110만)
- 얼굴+말 걸기(토킹헤드): 2초 시청 +14%, 얼굴/미소 +13% (VidMob)
- 호기심/반직관: 4만 개 DTC 상위 공통 ("혀가 하얗다면…")
- 콜아웃형("○○하는 사장님들") 단독 대규모 실측: 모름 (관행 광범위, 공개 데이터 없음)
- 적용: 소재 1개당 훅 1유형. 최소 3유형(콜아웃/결과 먼저/반직관) × 같은 본체

## D2. 영상 훅 — hook rate 기준

- **hook rate = 3초 시청 ÷ 노출**
- TikTok 공식: CTR 상위 영상의 63%가 첫 3초 내 후킹; Facebook 공식: 3초 본 사람의 65%가 10초+, 45%가 30초+ 시청
- **벤치마크 (Motion 55만 개, 2026): 25% 미만 = 도입부 재작업 / 25~35% = 보통 / 35%+ = 강함** (릴스는 5~10%p 낮게 [경험칙])
- 적용: 3초 재생÷노출 커스텀 지표 저장. 25% 미만이면 본체 수정 전에 첫 3초만 교체. 첫 프레임 = 얼굴+텍스트 오버레이+움직임

## D3. 텍스트 훅 — 첫 125자 공식

- 공식: **[타겟/문제 콜아웃] + [구체 결과·숫자] + [행동 지시]**를 첫 문장에
- 예: "오후 3시마다 허리 끊어질 것 같은 사무직이라면 — 앉자마자 다른 방석, 오늘 무료배송."
- 브랜드명으로 시작하는 카피 금지 (99%가 컷오프 앞만 읽음 — C6 근거)

## D4. 모듈식 훅 테스트

- 본체(데모·후기·CTA) 고정 + 첫 1~3초 훅만 3~5개 교체 생산; 3:2:2 방식 (소재3×본문2×헤드라인2 DCT — Tichenor 계열 [3자])
- 훅이 가장 빨리 피로 (고성과 훅 7일 후 −37% [운용사 주장, 추정]) → 훅만 교체가 최저비용 리프레시
- 적용: 영상 1편 촬영 시 훅 컷 5개 같은 날 촬영 (질문/결과/반직관/콜아웃/데모). 이미지는 상단 헤드라인 띠만 교체
