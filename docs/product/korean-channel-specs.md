# 국내 소상공인 채널 규격

## 한 장 요약

콘텐츠를 만들 때 채널 이름만 적지 않고, 공식 문서에서 확인한 메시지 유형과 확인 날짜를
함께 사용한다. 이 표는 문안·파일 규격을 고르는 기준이며 자동 게시 권한을 뜻하지 않는다.
현재 플랫폼은 외부 채널을 읽거나 게시하지 않으므로 사장님이 공식 화면에서 최종 확인한다.

## 입력 경계

- URL만 있으면 `external source unavailable`로 중단하고 읽었다고 표시하지 않는다.
- 제공 원문에는 URL, 확인일, 최소화된 본문의 SHA-256을 기록한다.
- 고객 이름·전화·이메일은 모델 입력 전에 익명화한다.
- 공개 매장 전화는 용도와 승인 값이 함께 있을 때만 모델 입력·결과에 유지한다.
- 외부 읽기·게시 연동이 추가되면 이 표의 공식 문서와 확인일을 먼저 갱신한다.

## 다음 단계

1. 개발자는 채널 규격 표의 확인일과 공식 URL을 분기마다 재검증한다.
2. 운영자는 생성된 문안을 공식 관리자 화면에서 검토하고 직접 게시한다.
3. 외부 연동을 구현할 때 채널별 인증·승인·오류 계약을 별도 gate로 추가한다.
