## 한 장 요약

### 합성 데이터로 확인한 미국 개인정보 처리 한계

기준 SHA에서 다음 로컬 명령을 실행했다. 실제 고객 정보와 외부 API는 사용하지 않았다.

```powershell
@'
from aicmo.redaction import minimize_customer_pii
for value in [
    'Customer name: Jane Doe; phone: +1 (202) 555-0100',
    '고객명: 홍길동; 전화: 010-1234-5678',
]:
    print(minimize_customer_pii(value))
'@ | .venv\Scripts\python.exe -
```

관찰 결과: 영문 이름·미국 번호는 그대로 남았고, 한국어 표본은 `고객명: [customer-name]; 전화: [customer-phone]`으로 바뀌었다. 전체 개인정보 유형의 탐지율을 측정한 결과는 아니다. **미국 고객 데이터를 안전하게 처리한다는 주장은 현재 증거로 뒷받침되지 않는다.** 코드 수정은 T05에 남긴다.

## 실행 규칙

- `D`는 저장소 문서·개발·합성 검증, `H`는 사업 결정·실제 권리·계약·관할 적용 검토다. `D+H`는 증거를 따로 기록한다. 담당은 역할이며 담당자 개인 지정은 **[미확인]**이다.
- P0는 해당 데이터 전송·납품·판매 전에 해결해야 할 항목, P1은 적용되는 채널·지역·결제 기능을 켜기 전에 해결할 항목이다. P1도 법적 적용 대상이면 필수이며 일정상 후순위라는 이유로 생략하지 않는다.
- 아래 기한은 날짜 약속 대신 **활성화 전 게이트**다. 코드 작업은 기존 G 번호의 실행 범위에서 진행하고 같은 기능을 중복 구현하지 않는다. 문서 과제는 기존 decision record와 본 문서의 해당 절을 갱신한다.
- 증거는 `docs/product/implementation-evidence/`에 T ID별 검증 결과로 남긴다. 계약·고객 정보 원본은 비공개 보관하고 저장소에는 식별자·검증일·요약만 기록한다.
- 계약·보관기간·판매지역을 임의 확정하지 않는다. 준비 가능한 작업은 계속하며 같은 승인 질문을 반복하지 않는다. 이번 요청은 TODO 작성이며 아래 실행용 프롬프트를 자동 실행하지 않는다.
