# linkedin-founder-voice

## 목적

창업자/대표 1인칭 목소리의 LinkedIn 포스트를 고스트라이팅한다. 정직하고 구체적이며 인게이지먼트를 유도하는 파운더 보이스. Okara LinkedIn Agent에 해당하는 기능.

## 에이전트 조합

```
copywriter → reviewer
```

## 입력

```
BRAND: {client}        # 클라이언트명
PERSONA: {persona}     # 대표 화자 정보 (이름/직함/배경, 선택 — config에서 보완)
COUNT: {count}         # 포스트 수 (기본: 2)
THEME: {theme}         # 주제 (선택 — 없으면 아래 유형 로테이션)
SOURCE: {source}       # 소재 파일 (선택)
```

## 참조 문서

- `clients/{client}/config.md` — 회사, 대표 정보, ICP
- `clients/{client}/brand-guidelines.md` — 톤앤매너 (필수)
- `knowledge-base/{client}/winning-copy.md` — 반응 좋았던 포스트

## 파운더 보이스 유형 (THEME 미지정 시 로테이션)

| 유형 | 구조 | 예시 소재 |
|------|------|----------|
| 실수/배움 | 실패 서사 → 구체적 교훈 → 질문 | "첫 달에 ○○를 잘못했다" |
| 숫자 공개 | 실제 지표 → 맥락 → 인사이트 | 매출/전환율/채용 숫자 |
| 반박 | 업계 상식 → 왜 틀렸는지 → 근거 | "다들 ○○라고 하는데" |
| 비하인드 | 의사결정 과정 공개 | 기능 출시, 가격 결정 |
| 고객 스토리 | 고객 문제 → 해결 과정 (수치) | 사례 (허락 필요 표기) |

## 절차

### 1단계: 화자 보이스 캘리브레이션
- PERSONA + brand-guidelines + 기존 winning-copy에서 화자의 문장 리듬 파악
- 보이스 메모 3줄 작성 (문장 길이, 어휘 수준, 금지 톤)

### 2단계: 포스트 초안 작성
- LinkedIn 파운더 보이스 규칙:
  1. 첫 2줄이 훅 — "더 보기" 클릭 전에 궁금증 유발
  2. 1인칭 경험 기반 — 일반론/교훈 나열 금지
  3. 구체적 숫자·이름·날짜 (없으면 [미확인 — 대표 확인 필요] 태그)
  4. 겸손 + 자신감의 균형 — 자랑도 자기비하도 과하면 FAIL
  5. 마지막 줄은 질문 또는 담담한 마무리 — "공유 부탁" 류 CTA 금지
  6. 해시태그 0-3개, 이모지 최소
  7. 1,300자 이내 권장

### 3단계: 검토
- reviewer 검증:
  - [ ] 실제 대표가 쓴 것처럼 읽히는가 (AI 티/강연 톤 없음)
  - [ ] 구체성 — 숫자/사례가 있는가 ([미확인] 태그 포함)
  - [ ] brand-guidelines 준수

## 출력

`outputs/{client}/content/{YYYYMMDD}_linkedin-founder-voice.md`

```markdown
# LinkedIn 파운더 보이스 — {client} {date}
## 보이스 메모 (3줄)
## 포스트 1 ({유형}) — 전문 + 의도 + 예상 반응
## 포스트 2 ({유형}) — 전문 + 의도 + 예상 반응
## 대표 확인 필요 사항 ([미확인] 항목 정리)
```

## 금지 사항

- 자동 게시 금지
- 대표의 실제 경험이 아닌 스토리를 사실처럼 지어내지 말 것 — 소재 없으면 [미확인] 태그
- 직원/고객 실명·수치는 승인 전까지 플레이스홀더 처리
