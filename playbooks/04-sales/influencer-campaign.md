# influencer-campaign

## 목적

인플루언서/크리에이터 캠페인의 기획-매칭-아웃리치-브리프를 한 번에 설계한다. Okara Influencer Agent에 해당하는 기능 (단, 정산·계약 실행은 인간 승인 게이트 뒤 수동 처리).

## 에이전트 조합

```
researcher + strategist (병렬) → sales-writer → reviewer
```

- researcher: 채널 후보 발굴 (규모/톤/오디언스 적합도)
- strategist: 캠페인 구조 설계 (목표, 예산 비중, KPI)
- sales-writer: 아웃리치 메시지 + 캠페인 브리프 작성

## 입력

```
BRAND: {client}        # 클라이언트명
GOAL: {goal}           # 캠페인 목표 (인지도/전환/콘텐츠 확보)
BUDGET: {budget}       # 예산 규모 (선택 — 없으면 비중(%)만 제시, [미확인] 표기)
PLATFORM: {platform}   # 주 채널 (instagram/youtube/tiktok/blog, 기본: instagram)
TIER: {tier}           # 크리에이터 규모 (나노/마이크로/미드, 기본: 마이크로)
```

## 참조 문서

- `clients/{client}/config.md` — 제품, ICP, 업종
- `clients/{client}/brand-guidelines.md` — 톤앤매너
- `clients/{client}/pricing-rules.md` — 가격 정책 (협찬 제안 시)

## 절차

### 1단계: 캠페인 구조 (strategist)
- 목표별 캠페인 유형: 시딩(무상 제공) / 협찬 콘텐츠 / 공동구매·제휴 / 앰배서더
- KPI 정의: 도달/저장/댓글/프로모코드 전환
- 예산 미확인 시: 비중(%)만 제시 + "[미확인 — 클라이언트 인터뷰 필요]"

### 2단계: 크리에이터 매칭 (researcher)
- 후보 5-10개 발굴 (WebSearch — 플랫폼별 업종 크리에이터)
- 평가 기준:
  | 항목 | 확인 내용 |
  |------|----------|
  | 오디언스 적합도 | ICP와 팔로워 겹침 [추정] |
  | 인게이지먼트 질 | 댓글 질 (봇 의심 여부) |
  | 톤 적합성 | 브랜드 가이드라인과의 충돌 여부 |
  | 협찬 이력 | 경쟁사 협찬 여부, 협찬 빈도 |
- 각 후보에 [추정] 근거 1줄 필수

### 3단계: 아웃리치 + 브리프 (sales-writer)
- 후보별 맞춤 제안 메시지 (DM/이메일 초안):
  - 상대 콘텐츠 구체 언급 → 왜 이 브랜드와 맞는지 → 명확한 제안 조건 → 부담 없는 CTA
- 캠페인 브리프 (수락 후 전달용):
  - 필수 전달 요소 / 톤 가이드 / 금지 사항 / 광고 표시 의무(#유료광고) / 일정

### 4단계: 검토
- reviewer 검증:
  - [ ] 후보 평가에 [추정] 근거가 있는가
  - [ ] 공정거래위원회 경제적 대가 표시 의무 안내가 있는가
  - [ ] 계약·정산이 인간 승인 게이트 뒤로 되어 있는가

## 출력

`outputs/{client}/sales/{YYYYMMDD}_influencer-campaign.md`

```markdown
# 인플루언서 캠페인 — {client} {date}
## 캠페인 구조 (유형/KPI/예산 비중)
## 크리에이터 후보 (우선순위순, 평가표)
## 아웃리치 메시지 초안 (후보별)
## 캠페인 브리프 (수락 후 전달용)
## 수동 처리 항목 (계약/정산/제품 발송)
```

## 금지 사항

- 자동 계약·자동 정산·자동 발송 금지 — 승인 게이트 뒤 수동 처리
- 팔로워 수 외 상세 지표(도달률 등)는 확인 불가 시 [미확인] 태그
- 경제적 대가 표시 누락 지시 금지 (공정위 위반)
