# ugc-video-brief

## 목적

UGC 스타일 숏폼 영상(광고/소셜용)의 가이드 브리프와 멀티 앵글 스크립트를 작성한다. 크리에이터에게 전달하거나 AI 영상 생성 도구에 입력할 수 있는 수준의 촬영/생성 지시서. Okara UGC Agent에 해당하는 기능.

> 기존 `visual-content-guide.md`가 사진 촬영 가이드라면, 이 플레이북은 영상(숏폼 UGC) 전용.

## 에이전트 조합

```
designer → reviewer
```

## 입력

```
BRAND: {client}        # 클라이언트명
PRODUCT: {product}     # 영상 대상 제품/서비스
GOAL: {goal}           # 목적 (광고/오가닉/리뷰/언박싱 등)
PLATFORM: {platform}   # 게시 채널 (instagram-reels/tiktok/youtube-shorts, 기본: instagram-reels)
COUNT: {count}         # 앵글/변형 수 (기본: 3)
```

## 참조 문서

- `clients/{client}/config.md` — 제품, ICP
- `clients/{client}/brand-guidelines.md` — 톤앤매너, 비주얼 무드
- `playbooks/03-content/hooking-copy.md` — 훅 문안 (영상 첫 3초에 재사용)

## 절차

### 1단계: 앵글 설계
- COUNT만큼 서로 다른 앵글 설계:
  | 앵글 유형 | 구조 |
  |---------|------|
  | 문제-해결 | 공감 문제 제시 → 제품 등장 → 결과 |
  | 리뷰/추천 | 실사용자 1인칭 → 구체적 장점 2-3개 |
  | 비교 | 이전 방식 vs 제품 사용 후 |
  | 비하인드/과정 | 제작/준비 과정 공개 |
  | 반응/변화 | 사용 전후, 첫 반응 |
- 각 앵글에 타겟 ICP 세그먼트 매핑

### 2단계: 스크립트 + 브리프 작성
- 영상당 구성:
  1. **훅 (0-3초)**: 스크롤 정지 문구/장면 — hooking-copy 패턴 재사용
  2. **본문 (3-25초)**: 장면별 스크립트 (대사/자막/화면 지시)
  3. **CTA (마지막 3-5초)**: 플랫폼별 적합한 행동 유도
  4. **촬영 지시**: 조명/앵글/소품/분위기 (디자이너 관점)
  5. **AI 생성 시 프롬프트 메모**: AI 영상 도구 입력용 장면 묘사 (해당 시)
- 길이: 15-30초 기본 (플랫폼별 조정)

### 3단계: 검토
- reviewer 검증:
  - [ ] 훅이 3초 내에 오는가
  - [ ] 브랜드 가이드라인 톤 준수
  - [ ] 광고 표시 의무(#광고 등) 안내 포함 여부 (유료 협찬 시)

## 출력

`outputs/{client}/design/{YYYYMMDD}_ugc-video-brief.md`

```markdown
# UGC 영상 브리프 — {client} {date}
## 앵글 맵 (앵글 × ICP 세그먼트)
## 영상 1: {앵글}
### 훅 / 장면별 스크립트 / CTA / 촬영 지시 / AI 생성 메모
## 영상 2, 3 ...
## 제작 체크리스트 (크리에이터 전달용)
```

## 금지 사항

- 실제 영상 파일 생성을 약속하지 말 것 — 산출물은 브리프/스크립트 (영상 생성은 별도 도구, 승인 게이트)
- 허위 사용 후기 연출 지시 금지 (실사용 기반 각색만)
- 플랫폼 광고 정책 위반 소재(과장 효능 등) 금지
