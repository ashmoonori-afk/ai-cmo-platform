# backlink-outreach

## 목적

백링크 확보를 위한 아웃리치 대상을 발굴하고, 링크를 받을 만한 자산(콘텐츠/데이터)과 아웃리치 메일 초안을 작성한다. Okara Link Broker Agent(로드맵)에 해당하는 기능.

> ⚠️ **스팸 정책**: 대량 템플릿 메일·링크 매매·PBN은 Google 스팸 정책 위반. 이 플레이북은 가치 기반 아웃리치(상호 이익이 있는 제안)만 다룬다.

## 에이전트 조합

```
researcher + seo-specialist (병렬) → sales-writer → reviewer
```

- researcher: 아웃리치 대상 사이트 발굴 (업계 블로그, 디렉토리, 언론, 파트너)
- seo-specialist: 링크 갭 분석 (경쟁사는 받고 우리는 못 받은 링크 유형)
- sales-writer: 아웃리치 메일 초안 (outbound-sequence 톤 원칙 재사용)

## 입력

```
BRAND: {client}          # 클라이언트명
SITE_URL: {url}          # 사이트 URL
ASSETS: {assets}         # 링크받을 자산 (가이드, 데이터, 도구 등, 선택 — 없으면 기존 콘텐츠에서 선정)
TARGETS: {targets}       # 직접 지정한 대상 사이트 (선택)
COUNT: {count}           # 아웃리치 대상 수 (기본: 10)
```

## 참조 문서

- `clients/{client}/config.md` — 업종, 제품
- `clients/{client}/brand-guidelines.md` — 톤앤매너
- `outputs/{client}/intelligence/` — 경쟁사 분석 (링크 갭의 기준)
- `playbooks/04-sales/outbound-sequence.md` — 콜드메일 작성 원칙

## 절차

### 1단계: 링크 갭 분석 (seo-specialist)
- 경쟁사가 인용되는 콘텐츠 유형 파악 (WebSearch: "{업종} 추천", "{업종} 통계" 등)
- 우리가 기여할 수 있는 자산 매칭: 데이터/가이드/도구/전문가 코멘트

### 2단계: 대상 발굴 (researcher)
- 유형별 대상:
  | 유형 | 예시 | 제안 각도 |
  |------|------|----------|
  | 업계 블로그/매체 | 관련 주제 기고 수용 매체 | 기고/전문가 코멘트 |
  | 리스트클 콘텐츠 | "~ TOP 10" 류 기존 글 | 목록 추가 제안 (근거 포함) |
  | 깨진 링크 보유 페이지 | 경쟁사 dead link 링크한 페이지 | 대체 자원 제안 |
  | 로컬 디렉토리/협회 | 업종 협회, 지역 디렉토리 | 등록 신청 |
- 대상별 담당자/연락 경로 조사 [미확인 시 표기]

### 3단계: 아웃리치 메일 초안 (sales-writer)
- 대상별 맞춤 1통씩 (템플릿 복붙 금지)
- 구조: 상대 콘텐츠 구체 언급 → 가치 제안 (왜 그들의 독자에게 도움인가) → 부담 없는 CTA
- 팔로업 1회분 초안 포함

### 4단계: 검토
- reviewer 검증:
  - [ ] 링크 매매·대가성 표현 없는가
  - [ ] 대상별 맞춤화가 실제로 되어 있는가 (이름/콘텐츠 언급)
  - [ ] 발송은 클라이언트가 직접 — 자동 발송 경로가 없는가

## 출력

`outputs/{client}/seo/{YYYYMMDD}_backlink-outreach.md`

```markdown
# 백링크 아웃리치 — {client} {date}
## 링크 갭 요약
## 대상 목록 (우선순위순)
### 대상 1: {site} — 유형 / 연락 경로 / 제안 각도 / 메일 초안 / 팔로업 초안
## 링크 자산 갭 (만들어야 할 자산 제안)
```

## 금지 사항

- 링크 구매, PBN, 대량 자동 발송 제안 금지
- 담당자 이메일을 추측으로 지어내지 말 것 — [미확인] 태그
