# 광고 운영 전략 라이브러리 (실험 설계 · 지표 해석 · 컨텐츠 · 후킹)

## 목적

메타·네이버 광고 SOP가 공용으로 참조하는 **검증된(proven) 전략 사전**. 4개 축으로 나뉘며, 각 전략은 "방법 → 근거 → 소액 계정 적용법" 구조다. 광고 산출물을 만들 때 여기서 전략을 골라 적용하고, 산출물에 전략명을 명시한다.

> 근거 전문: `docs/research/2026-07-03-ad-ops-strategies-research.md` (2026-07 딥리서치 — 플랫폼 공식/대규모 실측/운용사 자료 등급 구분, 배수 과장 주장 수록 금지 원칙)
> 사용처: `10-ads/meta-ads.md`, `10-ads/naver-search-ads.md` (중복 정의 금지 — 이 파일이 원본)

## 제1부. 실험 설계 전략 (5개)

### 실험1. 킬 룰 3중 게이트 (조기 판단 차단)

- **방법**: 소재/키워드를 끄는 기준을 기간이 아니라 지출·표본으로 고정 —
  ① 목표 CPA 2배 지출 + 전환 0 → 종료 ② 노출 1,000회 후 CTR 1% 미만 → 소재 문제 판정 ③ **72시간 내에는 ①외 킬 금지**
- **근거**: NPPR 2026, AdStellar (학습기 첫 48시간 CPA 3배 스파이크는 정상 변동)
- **소액 적용**: 소재당 일 1천~5천 원으로 시작해도 이 게이트만 지키면 조기 오판 대부분 방지 (한국 실무: polarad 2025)

### 실험2. 테스트→스케일 2캠페인 구조

- **방법**: 테스트 캠페인(예산 10~20%, 소재 3~5개, ABO 공정 비교) → 승자를 **Post ID 그대로** 스케일 캠페인(CBO/ASC)에 복제 투입
- **근거**: 업계 표준 구조 (Superscale·RebootIQ·Skaleit 공통); Meta 발표 2차 인용 — 세트 축소 광고주 CPA 68%↓, ASC 전환당 비용 17%↓
- **소액 적용**: 2캠페인이 상한. 그 이상 쪼개면 학습 파편화

### 실험3. 예산 분할 80/20 (소액판 70/20/10)

- **방법**: 검증된 곳 80% / 테스트 20%. 월 100만 원+면 70(검증)/20(확장)/10(실험) 3분할
- **근거**: 70/20/10은 Coca-Cola Content 2020·Google 채택 프레임 (Barrett Media 2024). 80/20 소액 변형은 [추정]
- **소액 적용**: 실험 몫 10%는 분기 1회 몰아서 (예: 어글리 애드 실험)

### 실험4. 네이버 소재 실험 — 동일비중 + 전환 판정

- **방법**: 그룹당 소재 2~3개를 **동일비중** 노출로 2~4주 → 전환(CVR) 기준 승자 확정 → 패자 교체. 확장검색은 예산 상한 10~20%로 켜서 "키워드 발굴기"로만 쓰고, 주 1회 검색어 리포트 → 전환 없는 검색어 제외 등록
- **근거**: 성과기반 노출은 클릭 확률 모델 기반(네이버 공지 전재 — 아이보스)이라 클릭↑≠구매↑, 전환 판정에는 동일비중이 우위 (브런치 파워링크 가이드)
- **소액 적용**: 이 루프(소재 A/B + 검색어 정리)가 네이버 소액 운영의 전부라 해도 과언 아님

### 실험5. 초간이 On/Off 증분 테스트

- **방법**: 분기 1회, ROAS가 유난히 좋은 의심 캠페인(리타겟팅·브랜드검색) 1개만 1~2주 OFF → **총매출 낙폭**과 그 캠페인의 보고 매출을 대조. 낙폭이 훨씬 작으면 증분 낮음 → 예산 재배분
- **근거**: Meta Conversion Lift는 최소 $30,000 요구로 소액 불가 (Triple Whale) → On/Off가 유일한 현실 옵션 (Funnel.io, Cometly 2026)
- **소액 적용**: 비용 0원. 광고비 재배분 인사이트로는 최대 효율

**보조 — 랜딩 실험**: 광고 고정 + 랜딩만 변형. Google Ads는 공식 Experiments로 50/50 분할 (공식 문서). "광고 2개에 URL 2개"는 알고리즘 편향으로 가짜 A/B (Blobr). 소액은 큰 차이(오퍼·가격 표시)만 테스트.

## 제2부. 지표 해석 전략 (5개)

### 지표1. 주간 MER 1줄 대시보드

- **방법**: **MER = 주간 총매출 ÷ 주간 총광고비** (전 채널 합산). 플랫폼 ROAS는 "어디에 쓸지" 상대 비교용, MER은 "더 쓸지" 절대 판단용
- **근거**: Meta 평균 ~28% ROAS 과대보고, 채널 합산 30~40% (AdsX); 같은 주문을 복수 플랫폼이 중복 청구 (Polar Analytics). 프레임 출처: Common Thread Collective
- **소액 적용**: 스프레드시트 1줄. 플랫폼 ROAS와의 갭을 매주 기록 → 자기 계정의 인플레이션율 파악

### 지표2. 판단 유예 룰 (최소 표본 게이트)

- **방법**: **목표 CPA 1~2배 지출 + 노출 1,000회 + 72시간**을 넘기 전에 킬/증액 금지. 이 표본으로는 "대패자 제거"만 가능하고 "미세 승자 확정"은 불가함을 인지
- **근거**: CRO 기준(변형당 전환 250~350건 — CXL)은 소액 불가 → 광고 실무 최소 게이트 (AdStellar, NPPR 2026). Meta 공식 A/B도 신뢰도 65% 미만이면 승자 미선언
- **소액 적용**: 주간 점검 체크리스트 첫 항목으로

### 지표3. 진단 트리 — 결정은 CPA로, 진단은 CTR/CVR로

```
CPA/MER 나쁨?
├─ CTR 벤치마크 미달        → 크리에이티브/타겟 문제 (소재 교체)
├─ CTR 정상 + CVR 낮음      → 랜딩/오퍼 문제 (페이지 수정)
├─ CTR·CVR 정상 + CPM 급등  → 경매/원가 문제 (타겟·시즌 확인)
└─ 둘 다 약함               → 증액 전에 크리에이티브부터
```

- **근거**: Digital Applied 2026 ("CTR이 건강한데 CVR이 낮으면 문제는 광고가 아니라 랜딩"), Pathlabs (지표 계층)
- **소액 적용**: 상위 지표(CPM/CTR)는 원인 진단에만, 예산 결정은 하위 지표(CPA)로만

### 지표4. 오독 체크리스트 6종

| 오독 | 실제 |
|------|------|
| 초기 과성과 = 승자 | 소표본 착시 — 주간 사이클 돌면 역전 빈번 (CXL, AdStellar) |
| CTR 높은 소재 = 승자 | 호기심 클릭 — CVR 낮은 조합 흔함 (KlientBoost) |
| 리타겟 ROAS 10배 = 효자 | 증분 대비 2~5배 부풀림, 진짜 증분 40% 사례 (Nine.am, Improvado) |
| 브랜드검색 ROAS = 광고 성과 | 오가닉이 공짜로 잡을 수요를 광고가 청구 (RightSideUp) |
| 채널 ROAS 합산 = 총성과 | 같은 주문 중복 청구 — 합산 > 실매출 (Polar Analytics) |
| 학습기 CPA 급등 = 실패 | 첫 48시간 3배 스파이크는 정상 (AdStellar) |

### 지표5. 윈도 고정 + 7일 롤링 비교

- **방법**: 어트리뷰션 윈도를 하나로 고정(리드젠 1일 클릭 / 이커머스 7일 클릭+1일 뷰)하고 기간 비교 시 절대 변경 금지. 성과 비교는 **온전한 주 단위(월~일) 7일 롤링**으로만
- **근거**: 윈도는 보고 수치와 알고리즘 최적화 대상을 둘 다 바꿈 (AdsManagement 2026); 전환율 요일 변동 최대 30% (LeadEnforce)
- **소액 적용**: 테스트 시작·종료를 같은 요일로 맞추면 주기 왜곡 자동 제거. 월 1회 "어트리뷰션 비교" 컬럼으로 1일 클릭 비중 확인

## 제3부. 컨텐츠(크리에이티브) 전략 (5개)

> 전제: 광고발 매출 상승분의 49%가 크리에이티브 요인 (Nielsen Catalina ~500캠페인). Andromeda(2024-12) 이후 크리에이티브가 곧 타겟팅이다.

### 컨텐츠1. 앵글 맵 먼저 (5앵글 프레임워크)

- **방법**: 제작 전에 소구점 지도 작성 — **문제-해결 / 사회적 증거(후기) / 창업자 스토리 / 비포-애프터 / 작동 원리** (+비교형). 이 중 3개 선택 × 앵글당 2~3변형
- **근거**: 4만 개 DTC 광고 분석(2025) 상위 브랜드 공통 패턴; **"실패→성공" 스토리가 순수 성공담 대비 IPM +78%** (AppsFlyer 110만 소재)
- **적용**: 앵글이 다르면 "다른 광고"로 인정 → 다양화 요건 충족. 비교형은 경쟁사 실명 대신 "구형 방식"을 적으로 (표시광고법 리스크 회피)

### 컨텐츠2. 저예산 다양화 — 진짜 다른 소재 3~5개

- **방법**: 광고세트당 컨셉이 다른 소재 3~5개 유지 (①UGC형 ②제품 포커스 ③문제/해결 ④비포애프터 ⑤후기형). 색·문구만 바꾼 변형은 다양화 아님
- **근거**: **Meta 공식 피로도 연구(실험 26,000건): 동일 소재 4회 노출 시 전환 가능성 약 −45%**; 상위 2% 소재가 광고비 43~53% 흡수 (AppsFlyer) — 위너는 소수라 계속 후보를 공급해야 함
- **적용**: 신규 소재는 실험2의 테스트 캠페인으로 공급

### 컨텐츠3. UGC/네이티브 스타일 (+어글리 20% 실험)

- **방법**: 폰 세로 촬영 + 자막 + 첫 컷에 사람 얼굴. "사장님이 직접 말하는", "직원이 써본", "리뷰 읽어주기" 포맷. 예산 20%로 어글리 실험(카톡 스크린샷 스타일, 손글씨 가격표) 병행
- **근거**: Meta Performance 5 공식 기둥; VidMob 실측(1,678개 광고) — 일반인 오프닝 +20%, 토킹헤드 2초 시청 +14%; 어글리 애드는 부분 검증(Pattern Brands "4개 중 3개 승리" — 대규모 실측 미확보)
- **적용**: 의료 등 신뢰 중심 업종은 폴리시드 유지. "UGC 3~5배" 류 배수 주장은 근거 미공개 — 인용 금지

### 컨텐츠4. 첫 125자 카피 규칙

- **방법**: 프라이머리 텍스트 첫 125자(한글 체감 60~80자)를 광고 전체로 취급 — 훅+오퍼+CTA가 컷오프 안에. 이하는 읽는 1%를 위한 상세(스펙·후기·FAQ)
- **근거**: Meta 공식 권장 125자; "더 보기" 클릭 ~1.05% 실측 = 99%는 첫 줄만 읽음. 단 장문이 항상 손해는 아님 — 콜드·설명형 제품은 3문단이 CPA 최저 (AdEspresso 실험, 2018 — 오래된 실험임을 명시)
- **적용**: 단문 1개 + 중장문 1개를 항상 같이 테스트

### 컨텐츠5. 리프레시 루틴 — 훅만 갈아끼우기

- **방법**: 주간 점검에서 ①7일 빈도 3 초과 ②CTR 피크 대비 −25% 중 하나면 리프레시. 전면 재제작이 아니라 **위너 본체는 유지하고 첫 3초/헤드라인만 교체**. 최소 루틴: 2주 1회 신규 소재 2개
- **근거**: Meta 공식 4회 노출 −45% + 광고관리자 "크리에이티브 피로" 상태 표시; Andromeda 이후 수명 2~3주로 압축 [업계 종합, 추정]; TikTok 공식 "신규 그룹 생성보다 기존 그룹에 새 소재 추가"
- **적용**: 제4부 후킹4(모듈식 제작)와 세트로 운용

## 제4부. 후킹 전략 (5개)

### 후킹1. 첫 3초 룰 + hook rate 게이트

- **방법**: hook rate(3초 시청 ÷ 노출)를 커스텀 지표로 저장. **25% 미만 = 도입부 재작업 / 25~35% = 보통 / 35%+ = 강함** (릴스는 5~10%p 낮게 봄 [경험칙]). 25% 미만이면 본체 수정 전에 첫 3초만 교체
- **근거**: TikTok 공식 — CTR 상위 영상의 63%가 첫 3초 내 후킹; Facebook 공식 — 3초 본 사람의 65%가 10초+ 시청; 벤치마크는 Motion 2026 (광고 55만 개 실측)
- **적용**: 첫 프레임 3요소 = 얼굴 + 텍스트 오버레이 + 움직임

### 후킹2. 결과 먼저 (payoff-first) / 변화 스토리

- **방법**: 과정이 아니라 결과·변화를 0초에 보여준다. "실패 → 성공" 구조가 순수 성공담보다 강함
- **근거**: AppsFlyer 110만 소재 — 실패→성공 스토리 IPM +78%
- **적용**: 비포-애프터가 강한 로컬 업종(음식점·뷰티·학원·시공)에 1순위

### 후킹3. 텍스트 훅 공식 — 콜아웃 + 구체 숫자 + 행동

- **방법**: 첫 문장 = **[타겟/문제 콜아웃] + [구체 결과·숫자] + [행동 지시]**. 브랜드명으로 시작 금지
- **예시**: "오후 3시마다 허리 끊어질 것 같은 사무직이라면 — 앉자마자 다른 방석, 오늘 무료배송."
- **근거**: 99%가 컷오프 앞만 읽음 (컨텐츠4); 얼굴+말 걸기 실측 +13~14% (VidMob); 콜아웃형 단독 대규모 실측은 모름 — 자체 테스트 대상
- **적용**: `03-content/hooking-copy.md`의 후킹 공식 8종과 교차 사용

### 후킹4. 모듈식 훅 테스트 (같은 본체 + 훅 3~5개)

- **방법**: 영상 본체(데모·후기·CTA)는 고정, 첫 1~3초 훅만 3~5종 교체 생산 (질문형/결과형/반직관형/콜아웃형/데모형 — 촬영일에 훅 컷을 한꺼번에). 이미지는 상단 헤드라인 띠만 교체. 3:2:2(소재3×본문2×헤드라인2) DCT 조합도 활용 가능 [운용사 방법론]
- **근거**: 훅이 가장 빨리 피로 (고성과 훅 7일 후 −37% [운용사 주장, 추정]) → 훅 교체가 최저비용 리프레시
- **적용**: 제작비를 늘리지 않고 소재 수를 늘리는 소상공인 핵심 기법

### 후킹5. 한국형 훅 보정 (자체 테스트 필수)

- **방법**: 검증된 국내 패턴부터 시작하되, **클라이언트별 훅 3종 자체 테스트 → KB(winning-copy.md) 축적**을 기본 절차로
- **근거 (부분적 — 대규모 국내 실측 없음)**: 역설 훅("학생 안 받습니다")으로 DB 단가 1/2~1/3 [대행사 보고, 추정]; 직관 혜택 훅("0원", "환불 보장") 국내 실무 합의; 네이버 GFA는 인물 이미지 CTR 우위 + 할인율 부각 (가비아CNS); 숏폼 주목도 1위 = 제품 특징 중심 정보성 (메조미디어 2025)
- **적용**: 허위·과장 불가 — 역설 훅도 사실이어야 함 (deliverable-standard 9번: "매출 보장" 금지와 동일 선상)
